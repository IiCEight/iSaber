Review notes

  1. The hero occupies a full screen. Oversized typography and overlapping graphics share its canvas; the short introduction and articles follow below.
  2. One article layout serves every subject. Categories are optional metadata, not fixed content types.
  3. Article imagery is optional. This structure works with the existing API without a new cover-image field.
  4. The reference screenshot informs the full-bleed blocks, overlapping circles, and large lower-edge typography. Navigation runs horizontally across the top as requested. Grayscale is still a wireframe choice, not a final palette.
  5. The header and section heading both reach Archive. The bottom invitation supports readers who finish the list; we can remove it if it feels repetitive.
